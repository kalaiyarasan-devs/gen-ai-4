# GenAI Image Preprocessing

## 📌 About the Project
Image Preprocessing is an important step in Computer Vision and Generative AI. It prepares images before they are given to an AI model. This project uses Python to resize, normalize, convert, and enhance images to make them suitable for AI applications.

## 🎯 Objectives
- Prepare images for AI model processing.
- Resize images to the required dimensions.
- Improve image quality and consistency.
- Convert images into suitable formats for machine learning.
- Learn the basics of computer vision.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Libraries:** OpenCV, Pillow, NumPy
- **Environment:** VS Code / Jupyter Notebook

## ✨ Features
- Image resizing.
- Image format conversion.
- Noise reduction.
- Image enhancement.
- Grayscale conversion.
- Pixel normalization.
- Brightness and contrast adjustment.

## ⚙️ Installation

Install the required libraries:

```bash
pip install opencv-python pillow numpy
```

## ▶️ How to Run

1. Install Python and the required libraries.
2. Create a Python file named `image_preprocessing.py`.
3. Place the input image in the project folder.
4. Run the program:

```bash
python image_preprocessing.py
```

5. The processed image will be saved to the output folder.
